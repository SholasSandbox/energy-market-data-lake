# The 7Rs of Cloud Migration

| Strategy | Description |
| :---- | :---- |
| Rehost | A "lift and shift" approach where an application is migrated from an on-premises Linux host to an equivalent instance on AWS. |
| Replatform | Migrating an application with minimal changes; for example, moving an on-premises database like Oracle RDBMS on AIX to Amazon RDS for PostgreSQL. |
| Refactor | Extensive modification or modernization of an on-premises application, such as refactoring a monolithic application hosted on VMware into a microservices architecture on AWS. |
| Repurchase | Replacing a self-hosted application with its SaaS equivalent. |
| Retain | Keeping an on-premises application unchanged without migrating it to AWS. |
| Retire | Decommissioning an on-premises application rather than migrating it to AWS. |
| Relocate | Migrating an application to the cloud while maintaining hypervisor compatibility, such as moving VMware workloads to VMware Cloud on AWS. |
