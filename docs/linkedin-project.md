## Project title

Energy Market Data Lake

## One-line version

Built a cost-optimized AWS data lake for UK and EU energy market data using Lambda, S3, Glue, Athena, EventBridge, Step Functions, and an operator-focused React dashboard.

## Profile-ready description

Designed and deployed an AWS-based energy market data lake that ingests UK and EU electricity and gas datasets, stores raw data in S3, transforms it into partitioned Parquet with Glue, and analyzes it through Athena. Added a schema-validated news and AI insight workflow using Lambda, Step Functions, S3 artifacts, and failed-run quarantine. Built an operator-focused React dashboard that presents alerts, executive KPIs, P&L drivers, hedge coverage, market context, source references, and data-quality status from approved public snapshot JSON. Focused on cost control through lifecycle policies, partitioning, serverless orchestration, and avoiding always-on infrastructure.
